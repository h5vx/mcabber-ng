
 /BIND [key [= command line]]

Bind the command line to a key combination.  Keys are given by name, like "Alt+j", "Ctrl+Left", "F5" or "Ctrl+Shift+PgUp".  To find the name of a key, press it: unbound keys are reported in the log window ("Unknown key: Alt+j").

/bind
 Display the list of current bindings
/bind key
 Display the command line bound to this key
/bind key =
 Remove the binding of "key"
/bind key = command line
 Bind "command line" to the key

Modifiers: Ctrl (C), Alt (Meta, M), Shift (S), joined with "+" or "-".
Named keys: Enter, Tab, Backspace, Esc, Space, Up, Down, Left, Right, Home, End, PgUp, PgDn, Ins, Del, F1..F63, WheelUp, WheelDown.  Any other key is a single character: "Alt+j", "Alt+ж", "Ctrl+=".
Example: "/bind F5 = roster toggle_offline"
Note: some combinations cannot be distinguished by the terminal (Ctrl+i is Tab, Ctrl+m is Enter).
Tip: aliases also can be used instead of commands.
